# بوابة عين صالح

موقع تعريفي مستقل بولاية عين صالح في الجزائر، مبني بتقنيات الويب الأساسية دون إطار عمل أو أدوات بناء.

## الملفات
- `index.html`: هيكل الصفحة ومحتواها العربي.
- `styles.css`: الهوية البصرية والتصميم المتجاوب.
- `script.js`: القائمة المتنقلة وتأثيرات الظهور.
  
## تشغيل الموقع محليًا
افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا بسيطًا من مجلد المشروع.

## النشر المجاني عبر GitHub Pages
1. افتح المستودع ثم **Settings**.
2. اختر **Pages** من القائمة الجانبية.
3. ضمن **Build and deployment** اختر **Deploy from a branch**.
4. اختر الفرع `main` والمجلد `/(root)` ثم اضغط **Save**.
5. انتظر اكتمال النشر، وسيظهر رابط الموقع في صفحة Pages.

## ملاحظات تحريرية مهمة
- هذا مشروع مستقل وغير تابع لأي جهة حكومية.
- يجب التحقق من المعلومات التاريخية والثقافية محليًا وإضافة مراجع موثوقة قبل النشر النهائي.
- صور الأقسام الحالية رسوم زخرفية CSS وليست صورًا فوتوغرافية أو توثيقًا لمواقع بعينها.
- بريد التواصل في الصفحة تجريبي (`contact@example.com`) ويجب استبداله أو إزالة رابط المساهمة قبل الإطلاق.
- زر اللغة الفرنسية مؤقت، ولا يدّعي وجود ترجمة مكتملة بعد.
- الخريطة مقدمة من OpenStreetMap، وقد تحتاج إلى اتصال بالإنترنت حتى تظهر.

## الهوية
ألوان مستوحاة من الرمل والواحات والعمارة الصحراوية، مع اتجاه عربي RTL وتصميم متجاوب للهواتف والحواسيب.
