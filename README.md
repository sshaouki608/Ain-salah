# بوابة عين صالح

موقع تعريفي مستقل بولاية عين صالح في الجزائر، مبني بتقنيات الويب الأساسية دون إطار عمل أو أدوات بناء.

## الملفات
- `index.html`: هيكل الصفحة ومحتواها العربي.
- `styles.css`: الهوية البصرية والتصميم المتجاوب.
- `script.js`: القائمة المتنقلة وتأثيرات الظهور.
  
## تشغيل الموقع محليًا
افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا بسيطًا من مجلد المشروع.

## النشر المجاني عبر GitHub Pages
1. افتح المستودع ثم **Settings**.
2. اختر **Pages** من القائمة الجانبية.
3. ضمن **Build and deployment** اختر **Deploy from a branch**.
4. اختر الفرع `main` والمجلد `/(root)` ثم اضغط **Save**.
5. انتظر اكتمال النشر، وسيظهر رابط الموقع في صفحة Pages.

## ملاحظات تحريرية مهمة
- هذا مشروع مستقل وغير تابع لأي جهة حكومية.
- يجب التحقق من المعلومات التاريخية والثقافية محليًا وإضافة مراجع موثوقة قبل النشر النهائي.
- صور الأقسام الحالية رسوم زخرفية CSS وليست صورًا فوتوغرافية أو توثيقًا لمواقع بعينها.
- بريد التواصل في الصفحة تجريبي (`contact@example.com`) ويجب استبداله أو إزالة رابط المساهمة قبل الإطلاق.
- زر اللغة الفرنسية مؤقت، ولا يدّعي وجود ترجمة مكتملة بعد.
- الخريطة مقدمة من OpenStreetMap، وقد تحتاج إلى اتصال بالإنترنت حتى تظهر.

## الهوية
ألوان مستوحاة من الرمل والواحات والعمارة الصحراوية، مع اتجاه عربي RTL وتصميم متجاوب للهواتف والحواسيب.

## إضافة الصور بسهولة

1. ارفع صورك إلى `assets/images/`.
2. افتح `images.js`.
3. غيّر اسم الملف فقط بجانب المكان المطلوب.

| المفتاح | مكان الصورة |
|---|---|
| `hero` | الواجهة الرئيسية |
| `ksar` | بطاقة القصور والعمارة |
| `oasis` | بطاقة الواحات |
| `crafts` | بطاقة الحرف والعادات |
| `dunes` | قسم الطبيعة والكثبان |

مثال: إذا رفعت `my-photo.jpg` للواجهة، اكتب `hero: "my-photo.jpg",`.
اكتب الامتداد كما هو تمامًا، وانتبه للأحرف الكبيرة والصغيرة. الصيغ المقترحة JPG وPNG وWebP. إذا كان الاسم غير موجود فستبقى الرسمة الأصلية ظاهرة.


## الصور الفوتوغرافية الحالية ومصادرها

تُحمّل بعض الصور مباشرة من Wikimedia Commons، ولا تُخزّن كملفات داخل المستودع في الوقت الحالي. يلزم اتصال بالإنترنت لعرضها.

- صورة المدينة: [In Salah عين صالح 1.jpg](https://commons.wikimedia.org/wiki/File:In_Salah_%D8%B9%D9%8A%D9%86_%D8%B5%D8%A7%D9%84%D8%AD_1.jpg) — Habib Kaki — CC0.
- صورة النخيل: [In Salah Palmerie.jpg](https://commons.wikimedia.org/wiki/File:In_Salah_Palmerie.jpg) — Xeiswolf — CC BY-SA 4.0.
- صورة الكثبان: [In Salah Düne.jpg](https://commons.wikimedia.org/wiki/File:In_Salah_D%C3%BCne.jpg) — Xeiswolf — CC BY-SA 4.0.

تُعرض صورة الحرف كتصميم زخرفي مؤقتًا حتى تتوفر صورة موثقة للحرف المحلية. لا نضع صورة عامة ونسميها حرفة من عين صالح دون تحقق.

## استخدام رابط صورة بدل اسم ملف
يمكن أن تكون القيمة في `images.js` رابطًا مباشرًا يبدأ بـ `https://`، أو اسم ملف موجودًا في `assets/images/`.
